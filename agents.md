# AGENTS.md

> Контекст для AI-агентов (Claude, GPT, Copilot Workspace, Cursor, Aider и т.д.), работающих с этим репозиторием.

---

## 🎯 Проект в одном абзаце

**YouTube TTY + Neural Background** — это набор из **двух файлов** (CSS + JS), которые превращают YouTube в плоский фосфорно-зелёный терминал с живой нейросеткой на canvas. CSS внедряется через расширение **Enhancer for YouTube** (или Stylish/Stylus), JS — через то же расширение либо **Tampermonkey**. Никакого билда нет: правим файлы напрямую, пользователь копирует их в расширение и жмёт Ctrl+F5.

## ⛔ ЖЁСТКИЕ ПРАВИЛА (нарушать нельзя)

### CSS

1. **Никакого неона, свечения, теней, градиентов.** Принципиально. Проект — про **плоский фосфорный терминал**.
2. **`border-radius: 0 !important` везде.** Все скругления убиваются глобально.
3. **Моноширный шрифт форсится на `ytd-app *`.** Не добавляй исключений для «красоты».
4. **Не менять порядок секций 0–22.** Секция **22** (бейдж длительности) — самая хрупкая: она ломалась трижды. Любая правка — только с воспроизведением на реальной странице YouTube.
5. **Не использовать wildcard `[class*="..."]` без нужды.** Из-за них был баг с дублированием длительности (v3 → v4).
6. **Не форсить `visibility`/`opacity`/`display` на элементах YouTube.** Если YouTube что-то скрывает — пусть скрывает.
7. **Панели = сплошной `#000`.** Полупрозрачный `rgba(0,0,0,0.9x)` не годится — сквозь него видна нейросетка, а не должно.

### JS

1. **Никаких зависимостей.** Vanilla, IIFE, `'use strict'`.
2. **Не трогать DOM YouTube напрямую.** JS **только** создаёт `<canvas id="neural-bg-canvas">` и рисует.
3. **Не добавлять `MutationObserver` в этот файл.** Если нужен DOM-патч — выноси в отдельный модуль (обсуждаемо).
4. **Не менять `id="neural-bg-canvas"`.** На него завязан CSS (`z-index`, `position: fixed`).
5. **Защита от повторного запуска** (`__neuralInited`) должна сохраняться — иначе на SPA-навигации YouTube нарисуется 5 канвасов.

### Общие

1. **Никаких трекеров, аналитики, внешних запросов.** Приватность прежде всего.
2. **Не добавлять `eval`, `Function()`, `innerHTML` с user-input.**
3. **Не менять лицензию.** MIT.
4. **`CHANGELOG.md` обновляется в каждом PR.** Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
5. **Не коммитить скриншоты, `.DS_Store`, `node_modules`, `.vscode/`.** См. `.gitignore`.

## 🧠 Доменные знания (то, что легко забыть)

### Разметка YouTube меняется каждый квартал

YouTube активно **мигрирует** старые Polymer-компоненты на новые «view model»-компоненты. Что это значит:

| Старое (2020–2023)                                  | Новое (2024+)                                    |
|-----------------------------------------------------|--------------------------------------------------|
| `ytd-thumbnail-overlay-time-status-renderer`        | `yt-thumbnail-overlay-time-status-view-model`    |
| `ytd-thumbnail-overlay-resume-playback-renderer`    | `yt-thumbnail-overlay-progress-bar-view-model`   |
| `ytd-video-renderer`                                | `lockupViewModel` + `yt-lockup-view-model`       |
| `badge-shape` (Polymer)                             | `badge-shape` (Lit, класс `.yt-badge-shape`)     |

**Когда правишь CSS — всегда добавляй селекторы для обоих вариантов** (старый + новый). Так было с бейджем длительности: v3 сломался, v4 — фикс.

### Бейдж длительности — история багов

1. **v1:** бейдж не виден вообще. Причина: глобальный `box-shadow: none` убивал подложку.
2. **v2:** бейдж виден, но пропадает у некоторых. Причина: селекторы цепляли только старый рендерер.
3. **v3:** бейдж виден **дважды**. Причина: wildcard `[class*="badge-shape"]` + `visibility: visible !important` раскрыли скрытый дубликат.
4. **v4 (текущая):** точечные селекторы, никаких `visibility`/`opacity`/`display`, явное убийство `::before`/`::after` у старого бейджа.

**Если YouTube снова сломает бейдж** — сначала открой DevTools (F12), найди элемент, посмотри Computed Styles, выясни какие классы у контейнера. **Не гадай.**

### Firefox vs Chromium

- Проект изначально тестировался на **Firefox 156**. `backdrop-filter` в FF рендерится иначе — поэтому в CSS стоят оба префикса (`backdrop-filter` и `-webkit-backdrop-filter`).
- В FF `:is()` поддерживается с версии 78, можно использовать.
- `@layer` в FF 97+, тоже можно, но пока не используется — не хотим усложнять.

### SPA-навигация YouTube

YouTube **не перезагружает страницу** при переходах между `/watch`, `/results`, главной. Скрипт `neural-bg.js` инициализируется один раз и живёт всё время. **Канвас не пересоздаётся**, `resize` обрабатывается через `window.addEventListener('resize')`.

**Что это значит для правок:** если добавишь MutationObserver — не забудь про reconnect, иначе на SPA-переходах потеряешь наблюдение.

## 🔧 Рецепты частых правок

### Добавить новую секцию в CSS

1. Вставь **перед секцией 22** (бейдж — самая капризная, её всегда держим в конце).
2. Пронумеруй: если между 15 и 16 — переименуй всё после (не оставляй «15.5»).
3. Обнови `CHANGELOG.md` в `[Unreleased] → Added`.

### Поправить палитру

1. Правится **только** блок `:root` в начале CSS.
2. **Не хардкодь цвета в других секциях** — везде используй `var(--fg)`, `var(--fg-meta)` и т.д.
3. Если появляется новый оттенок — сначала добавь переменную, потом используй.

### Поправить нейросетку

1. Все настройки — в объекте `CFG` в начале `neural-bg.js`.
2. Формулы движения — в `frame()`. Порядок: **update → link lines → dots**. Не переставляй — линии должны быть под точками.
3. Если добавляешь параметр — добавь его и в таблицу в `README.md` и `docs/CUSTOMIZATION.md`.

### Обновить `CHANGELOG.md`

```markdown
## [Unreleased]

### Added
- ...

### Fixed
- ...
```

При релизе:
1. Переименуй `[Unreleased]` в `[X.Y.Z] — YYYY-MM-DD`.
2. Добавь новый пустой `[Unreleased]` сверху.
3. SemVer: **MAJOR** для ломающих изменений селекторов, **MINOR** для новых фич, **PATCH** для фиксов.

## 🚫 Антипаттерны (что НЕ делать)

| ❌ Плохо                                                 | ✅ Хорошо                                          |
|---------------------------------------------------------|---------------------------------------------------|
| `[class*="badge"] { visibility: visible !important; }`  | Точечно: `yt-badge-shape.yt-badge-shape { ... }`  |
| `background: rgba(0,0,0,0.9)` для панелей               | `background: #000`                                |
| `border-radius: 4px` (даже для «мелочи»)                | `border-radius: 0`                                |
| Добавлять `!important` без причины                      | Специфичность + точечный селектор                 |
| `document.querySelectorAll('ytd-*')` в JS              | Никаких DOM-операций, только канвас               |
| Коммит без обновления `CHANGELOG.md`                    | `CHANGELOG.md` в каждом PR                        |
| Правка секции 22 «по памяти»                            | Открыть YouTube, F12, проверить разметку          |

## 🧪 Как тестировать

**Билда нет.** Процесс такой:

1. Открой YouTube.
2. F12 → вкладка **Стили** → в расширении Enhancer замени CSS.
3. F12 → вкладка **Консоль** → вставь JS руками (или замени в Enhancer → Misc).
4. **Ctrl+F5** — жёсткая перезагрузка (обязательно, кэш Enhancer агрессивный).

**Проверь на этих страницах:**
- Главная (`/`)
- Результаты поиска (`/results?search_query=test`)
- Страница видео (`/watch?v=...`)
- Плейлист (`/playlist?list=...`)
- Shorts (`/shorts/...`)
- Меню аккаунта (клик по аватарке)
- Настройки YouTube (`/account`)

**DevTools — где смотреть:**
- Бейдж длительности → `Elements → Ctrl+Shift+C → клик по бейджу`
- Computed Styles → вкладка **Computed** справа
- Что перебивает → галочка **:hov** + **Filter** в Styles

## 📝 Формат коммитов

[Conventional Commits](https://www.conventionalcommits.org/):

```
<type>(<scope>): <subject>

<body>

<footer>
```

**Типы:**
- `feat:` — новая фича
- `fix:` — багфикс
- `docs:` — только документация
- `style:` — форматирование CSS (не влияет на поведение)
- `refactor:` — переписал без изменения поведения
- `chore:` — рутина (обновил зависимости, .gitignore)

**Примеры:**
```
fix(badge): восстановлено отображение длительности после v2024.10
feat(theme): добавлена янтарная палитра
docs(readme): обновлена таблица кастомизации
```

**Scope:** `badge`, `theme`, `neural`, `panel`, `player`, `search`, `docs`, `repo`.

## 🆘 Если ты (AI-агент) застрял

1. **Спроси пользователя скрин DevTools.** Без реальной разметки YouTube правки — гадание.
2. **Проверь последние изменения в селекторах YouTube.** Бывает, что класс поменялся без объявления.
3. **Не выдумывай CSS-свойства.** Если не уверен — проверь на [MDN](https://developer.mozilla.org/).
4. **Не удаляй существующие секции**, даже если они кажутся ненужными. Возможно, они лечат баг, которого ты не видишь.
5. **Сохраняй «плоский» стиль** — не предлагай «улучшения» вроде градиентов, теней, анимаций.
